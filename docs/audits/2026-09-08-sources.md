### Key source observations

- DR-DSN `main.py`: reward-only updates and final-epoch save; no test-F1 checkpoint maximization in inspected path. Read-only gtscore use when exporting output is distinct from training targets.
- VASNet `main.py`: `self.eval(self.test_keys)` each epoch and best F1 saved/reported. Treat test-named split as model-selection data.
- PGL-SUM `choose_best_epoch.py`: uses training-loss changes; do not conflate with VASNet checkpoint policy.
- SUM-GAN-AAE: separate multi-user and single synthesized-reference evaluation scripts; all epoch test results emitted, so final selection rule needs explicit documentation.
- DSNet `video_helper.py`: sample_rate counts decoded frames; default15 is2fps only at30fps, features are normalized1024-D GoogLeNet. Source includes custom raw-video dataset/inference tooling.
- Original dppLSTM: earlier HDF5 schema; two model binaries in tree; README data anchor missing concrete download URL. TVSum reference budget0.18 in code.
- VideoXum `utils.py#L275`: threshold indexed at floor(.15N), using >=. Distinct scores select floor(.15N)+1; ties can add more. `eval_v2vt_sum.py#L61` rank inputs use ten-user mean, while F1 keeps mean/max references. Loader max_frames512 and mismatch truncation should be reported.
- UniVTG QFVS: weighted bipartite semantic matching, separate query embeddings/tags, top_percent budget; explicit CUDA allocation and video4 mismatch trimming. TVSum implementation is highlight detection, not generic temporal F1 benchmark.
- FCSNA-QFVS author notebook: Colab `/content/drive/MyDrive/Research` paths, fixed20x200 layout, explicit CUDA, no pinned dependencies; supervised concepts and query tags.

### Source inspection caveats supplied by code audit

- [Zhang's pinned TVSum evaluator](https://github.com/kezhang-cs/Video-Summarization-with-LSTM/blob/0ee0a0948872544567ecede76868287042470f75/codes/evalTVSum/evaluate_TVSum.m) uses 0.18 for reference-summary capacity. The dppLSTM MATLAB decoder reweights scores using DPP diagonal information before mean-shot knapsack; record this separately from the paper's keyframe-density description.
- [VASNet main.py](https://github.com/ok1zjf/VASNet/blob/c3787531486f74789dc5e92758edf51e24f56e6d/main.py) selects the best epoch using test_keys F1. The paper record flags this; no clean validation-only reproduction is claimed.
- [VideoXum threshold](https://github.com/jylins/videoxum/blob/11bd4fe3fb51b7dc804dd1519a4914f67bff60df/utils.py#L275) takes threshold at zero-based floor(0.15*N), selects with >=, and can exceed 15%. [Correlation call](https://github.com/jylins/videoxum/blob/11bd4fe3fb51b7dc804dd1519a4914f67bff60df/eval_v2vt_sum.py#L61) passes averaged annotation scores, not per-user correlations averaged afterward.
