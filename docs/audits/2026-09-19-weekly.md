# Weekly literature and implementation audit — 2026-09-19

[Handbook home](../../README.md) · [Coverage ledger](../15-coverage.md) · [Source catalog](../generated/papers.md) · [Implementation catalog](../generated/resources.md)

This maintenance run covers new and newly indexed work after the 2026-09-08 audit, with a 30-day overlap beginning 2026-08-09. It also closes five documented historical gaps. The search is broad but not exhaustive, and this audit makes no field-wide state-of-the-art claim. A publication record means that its primary identity and stated method were checked; it does not mean that code ran or a result was reproduced.

## 1. Search coverage

The official arXiv API was scanned over submitted dates 2026-08-09 through 2026-09-19 for `cs.CV`, `cs.MM`, `cs.CL`, `cs.AI` and `cs.HC`. Date-split pagination covered 11,568 metadata records, avoiding the API's 10,000-result ceiling. Additional exact and adjacent queries were sorted by last update so older papers revised in the window were also considered.

Query families included video summarization/summary, highlight detection, long-form and egocentric summary, key moments/frames, query-focused and personalized summary, multimodal/video-language summary, synopsis/digest/recap/condensation, visual narrative, multi-video, online/streaming, and abstractive/extractive video output. Crossref, official publisher/proceedings pages, paper references, author project pages and GitHub exact-title/author searches supplemented arXiv. Search results were hypotheses until a primary paper or official metadata page confirmed them.

## 5. Numerical admission and corrections

Only four new benchmark rows were admitted: Kendall tau and Spearman rho for each dataset-specific best variant of Byra et al. Table 1. TVSum uses text plus synthetic-image descriptors with style transfer (`0.217`/`0.283`); SumMe uses text descriptors only (`0.088`/`0.108`) after Qwen2.5-VL category bootstrapping. Table 2's single “best variant” label is therefore not treated as one shared configuration. Sampling, prompts, API/model revisions, evaluated-video manifests, runs and uncertainty remain unknown, so every row is isolated.

Numbers were withheld when the source conflicted or when the protocol could not be made exact. This includes SGWIB's conflicting MoSu values and both datasets' split/count conflicts; TRINITY's split/count conflicts; M2UR's inaccessible tables; Wiley's incompatible 20%/mean-user protocol; Springer soccer event-detection rows; model-answered or LLM-judged proprietary agent studies; and paper-local sports splits without manifests.

The validator now bounds the registry's actual `Temporal-overlap F1` and `Frame-overlap F1` names when units are `percent`, and bounds all `correlation coefficient` values to the interval from -1 to 1. Earlier validation only recognized an unused F1 naming/unit combination.

## 6. Deferred, excluded and inaccessible candidates

- [Hybrid Spatio-Temporal Feature Representation](https://doi.org/10.21203/rs.3.rs-9730635/v1) is a low-evidence Research Square preprint with no dataset-specific final score, summary decoder/budget, reference aggregation or code; defer pending a stronger version.
- [HABSS](https://doi.org/10.1007/s44443-026-01222-3) explicitly produces a preprocessing candidate-frame pool rather than a final user summary; retain as a future adjacent-method audit.
- SVMemAgent, MarKey and other streaming/keyframe memory systems were excluded from the method registry because evaluation is VideoQA/memory accuracy rather than summary output/reference quality.
- Tutorial search and unified general editing papers without an explicit summary output were excluded. The Unified Agentic paper was admitted only because Task 2 has a defined audiovisual summary.
- FastPerson/QA-FastPerson are 2024 historical-source leads despite a 2026 thesis upload; they are not labeled as new 2026 methods.
- DeepSCN-TII, CTI-Sum and a digital-twin paper were outside the recent window by first-publication date despite later issue assignment.
- LiteViT and an AIP abstract-only candidate remain deferred because full text/output definition was inaccessible.
- M2UR's IEEE PDF produced HTTP 418/security challenge behavior and is recorded as restricted rather than missing. Its official metadata record remains useful without invented fields.

The required full repository link audit enumerated 370 unique external URLs. Every request returned the same environment-level `Temporary failure in name resolution` condition, so the report classified all 370 as `retry`/unresolved. This run therefore establishes neither recovery nor failure of any individual citation. No link was removed, and the prior 2026-09-08 snapshot remains the latest differentiated network observation for known 404, restricted and unresolved endpoints. The transient report was written to `/tmp/avs-link-report.json` as requested and is not a repository artifact.

## 7. Remaining gaps

No GPU training, paid API call, large artifact integrity pass or independent model score was run. External-link availability also needs a rerun from a network with functioning public DNS. Important next work includes QEVA and reference-free evaluation, FastPerson/QA-FastPerson, HABSS as preprocessing, multilingual summarization, multi-camera/cross-video summary benchmarks, medical/procedural domains, preference learning, and an exact fold-manifest audit for modern SumMe/TVSum studies. A controlled baseline reproduction should use a single public split manifest, fixed checkpoint rule and fully specified decoder before any ranking claim is made.
