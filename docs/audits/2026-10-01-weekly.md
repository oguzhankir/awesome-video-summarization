# Weekly literature and implementation audit — 2026-10-01

[Handbook home](../../README.md) · [Coverage ledger](../15-coverage.md) · [Paper catalog](../generated/papers.md) · [Dataset catalog](../generated/datasets.md)

This incremental maintenance run starts immediately after the 2026-09-19 scan and covers 2026-09-20 through 2026-10-01. It is selective, not an exhaustive proceedings census, and makes no field-wide state-of-the-art claim. Paper metadata, source inspection and author-reported results do not mean a model was reproduced.

## 1. Search coverage

The official arXiv API query was:

```text
all:video AND submittedDate:[202609200000 TO 202610012359] AND (cat:cs.CV OR cat:cs.MM OR cat:cs.CL OR cat:cs.AI OR cat:cs.HC)
```

The date-window scan returned **507 metadata records**. An accompanying last-updated-date query returned the same matching set; no earlier-submitted record surfaced in this query family. Titles and abstracts were screened for video summarization, highlight detection, keyframes/key moments, moment retrieval, multi-video reports and adjacent output tasks. The official arXiv records, primary PDFs, author project/repository pages and linked dataset cards were checked for admitted candidates. This is a metadata scan plus targeted source inspection, not a full-text census of every paper.

## 3. Candidate dispositions

- **Identity-Centric Video Summarization via Hierarchical Fusion of Biometric, Appearance, and 3D Body Features**, arXiv:2609.25837, was reviewed but not added as a new-window publication. The English preprint claims an earlier Spanish RIAI publication whose final volume/pages/DOI could not be resolved; its abstract and main result table also disagree on tracking metrics. It uses an unshared custom YouTube corpus, no author code was found, and subjective summary evaluation is deferred in the paper.
- **CueKFS** (arXiv:2609.31873) selects keyframes and evaluates downstream visual question answering rather than a summary-reference or summary-utility target; excluded from the method registry.
- **dKFD** (arXiv:2609.33083) focuses on event understanding/evidence selection and does not define a general video-summary output; excluded.
- **SumGround** (arXiv:2609.34598) is temporal grounding; excluded absent a summarization target.
- A Poisson-exchange paper mentions video summarization only as a possible application and has no summarization experiment; excluded.

## 4. Reproducibility and remaining gaps

The TSMD source tree was inspected at a pinned commit, including its configuration and smoke-test files, but no test, model or data was executed. EviDETR has an author project page but no code release located by exact-title/author searches. The MultiVENT-Raw GitHub repository at the recorded commit is a documentation/data-pointer repository, not an executable implementation. Large feature/media archives were not downloaded; no external-link audit was repeated. The previous 370-URL audit was inconclusive because every endpoint failed under the same execution-environment DNS condition.

No model score was independently reproduced. Modern QVHighlights split/feature manifest pinning, the restricted MultiVENT-Raw/MicroVENT artifacts, and the unresolved identity-centric publication record remain follow-up work.
